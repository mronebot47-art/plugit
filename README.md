# PlugIt

> "Know where you'll charge before you leave."

A modern, responsive EV charging and highway route planning platform for India.

## Core Features
- **Highway Route Planning**: Enter origin, destination, vehicle, and starting battery SoC.
- **Battery Ribbon Data Visualization**: Sawtooth curve showing SoC over distance with 10% min reserve.
- **Live Trip Simulation**: Real-time progress with Plan B failure rerouting.
- **Estimated Availability**: Double-peak highway demand model and community reports.

## Setup
```bash
npm install
npm run dev
```

Frontend runs on `http://localhost:3000`.
Backend API runs on `http://localhost:8000`.
